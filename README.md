# 합동과 대칭 미술관

『수학 5-2』 3단원 **합동과 대칭**을 스마트 패드로 공부하는 수업용 웹앱입니다.
스마트 패드로 하기에 알맞은 활동만 골라, 교과서의 이야기(다윤이와 승현이의 미술관 탐험)를 따라 전시실을 순서대로 돌면서

- **📘 배우기**: 교과서 순서대로 개념을 탐구하는 활동
- **🎮 익히기 게임**: 상황이 있는 게임으로 매번 새 문제를 반복 연습

을 할 수 있습니다. 설치나 로그인이 필요 없고, 웹 브라우저만 있으면 됩니다.

## 바로 사용하기

GitHub Pages를 켜면 아래 주소로 접속할 수 있습니다.

```
https://ykk1050.github.io/Congruence-and-Congruence/
```

> 처음 한 번만: 저장소 **Settings → Pages → Build and deployment**에서
> Source를 `Deploy from a branch`, Branch를 `main` / `(root)`로 선택하고 저장하세요.

컴퓨터에서 직접 열어 볼 때는 `index.html`을 브라우저로 열거나, 폴더에서 아래처럼 실행합니다.

```bash
python -m http.server 8765
```

## 전시실 구성 (교과서 순서)

| 전시실 | 📘 배우기 | 🎮 익히기 게임 |
| --- | --- | --- |
| 도형의 합동 | 디지털 투명 종이로 포개어 보기(예상→확인, 돌리기·뒤집기) · 모눈에서 합동인 도형 찾기 | **미술관 바닥 타일 수리** — 깨진 바닥에 꼭 맞는(합동인) 타일을 끌어서 끼우기 |
| 합동인 도형의 성질 | 도형을 직접 끌어 포개고 대응점·대응변·대응각 입력하기 · 대응변 길이·대응각 크기 비교 · 성질로 길이·각 구하기 · 퍼즐 조각 끼우며 대응 찾기 | **스테인드글라스 창문 수리** — 양쪽 창문에 짝을 이룬 합동인 유리 조각 중 금 간 조각을 새로 자르기 위해, 짝 조각에서 대응점·대응변·대응각 찾기, 몇 쌍인지 세기, 길이·각도·둘레 구하기 (맞히면 새 유리가 끼워짐) |
| 선대칭도형 | 대칭축 긋기(잘못 그은 선은 그 선으로 접었을 때의 모양을 보여 줌) · 대응점·대응변·대응각 입력하기 | **종이 작품 봉투에 바르게 넣기** — 게시판에 꽂힌 색종이 오리기 작품(나비·나뭇잎·도토리·펜토미노 등)을 꼭 맞게 겹치도록 접을 수 있는 선(대칭축) 모두 찾기, 잘못 그은 선은 접었을 때 삐져나오는 모습을 보여 주고, 다 찾으면 작품을 반으로 접어 봉투에 넣는 모습을 보여 줌 |
| 선대칭도형의 성질 | 대칭축을 따라 접어 대응변·대응각이 꼭 맞게 겹치는지 보고 길이·크기 비교하기 · 대응점끼리 이은 선분과 대칭축 살펴보기 · 공통된 규칙 추측해 쓰기(기기에 저장) · 점을 끌어 추측 검증하기 · 낱말 카드로 성질을 정리하며 내 추측과 비교하기 · 꼭짓점을 끌며 수직·같은 거리 탐구 · 성질로 구하기 · 완성 방법 알아보기 · 완성하기(비스듬한 대칭축 포함) · 도형판에 나만의 선대칭도형(친구와 주고받기) | **데칼코마니 작품 복원** — 물감이 칠해진 반쪽을 보고 선대칭도형 완성(완성하면 물감이 반대쪽에 거울처럼 찍힘) + 성질 퀴즈(길이·각도·둘레, 잘못 말한 친구 찾아 고치기) |
| 점대칭도형 | 점대칭도형 찾기(예상→180° 돌려 확인) · 대응점·대응변·대응각 입력하기 | **돌려도 같은 작품 전시실** — 새로 온 글자·도형 작품이 점대칭도형인지 판단(90°씩 두 번 돌려 확인), 180° 돌린 모양 예상하기, 점대칭도형이 아닌 까닭 고르기, 대칭의 중심 찾기, 대응점·대응변 → 작품을 ‘돌려도 같은 작품 전시실’ 또는 ‘다른 작품 전시실’로 옮겨 거는 모습이 보임 |
| 점대칭도형의 성질 | 대응변·대응각 재기 · 대응점 이어 대칭의 중심 찾기 · 성질로 구하기 · 완성 방법 알아보기 · 완성하기 | **바람개비 공원 만들기** — 점대칭도형 완성 + 성질 퀴즈(길이·각도·둘레, 잘못 말한 친구 찾아 고치기) |
| 단원 정리 | 용어 정리하기 | **교통안전 체험관 표지판 분류** — 체험관 앞 거리에서 새 표지판을 끌어 선대칭/점대칭/둘 다/둘 다 아님 보관함에 넣기 |

각 전시실의 **익히기 게임은 그 전시실의 배우기 활동을 모두 마쳐야 열립니다.** 시범이나 복습을 위해 주소 끝에 `#/open`을 붙여 열면 그 기기의 게임을 모두 열거나 다시 잠글 수 있습니다(학생 화면에는 링크 없음).

대응변·대응각은 어느 쪽부터 읽어도 정답입니다(예: 변 ㄹㅁ = 변 ㅁㄹ, 각 ㄹㅁㅂ = 각 ㅂㅁㄹ).
길이를 묻는 그림에는 어느 선분의 길이인지 호 모양 점선으로 표시하고, 길이 상자끼리 겹치면 자동으로 비켜 놓습니다.
그림 없이 묻는 단계(정리 문제 등)에는 앞 단계 그림을 ‘👀 앞 단계에서 본 그림’으로 함께 보여 주어 이전으로 돌아가지 않아도 됩니다.

## 지도서 반영 내용

- 학생용 화면이라 선생님 안내는 따로 두지 않고, 지도서의 **지도 방법**과 **학습 지도 및 평가의 주안점**을 활동 설계와 피드백에 녹였습니다.
- “예상하기 → 직접 확인하기 → 성질 정리하기” 흐름을 따릅니다.
- 그리는 방법을 외우기 전에 **어떤 성질을 이용할지 먼저 생각**하게 하고, 마지막에 방법을 순서대로 정리합니다.
- 대칭축이 모눈과 다른 방향일 때 **수선을 먼저 긋도록** 보조선 도구와 피드백을 제공합니다.
- 뒤집어서 포개어도 합동이라는 점, 가운데 점이 있다고 점대칭도형은 아니라는 점 등 지도서의 **오개념**을 피드백에 반영했습니다.
- 똑같이 둘로 나누는 선과 대칭축을 혼동하는 경우(평행사변형의 가운데 선 등)를 따로 짚어 줍니다.
- 180° 돌리기를 어려워하는 학생을 위해 **90°씩 두 번** 나누어 돌려 보여 줍니다.
- 성질을 말로 설명하는 활동으로 **잘못 말한 친구를 찾아 옳게 고치는** 문제를 넣었습니다.
- 대응점은 5학년 수준에 맞게 **꼭짓점인 경우만** 다룹니다.

## 구조

```
index.html        진입 화면
css/style.css     스타일 (패드 가로 화면 기준, 세로·휴대폰 대응)
js/core.js        DOM/SVG 도우미, 기하 계산(합동·대칭 판정), 저장, 소리
js/stage.js       모눈/도형을 그리는 SVG 무대와 터치 입력
js/ui.js          공용 부품: 단계 진행, 선택·빈칸 문제, 대응 찾기, 대칭축 긋기, 대칭도형 완성, 도형판
js/scenes.js      전시실마다 상황을 보여 주는 장면 그림
js/shapes.js      무작위 문제 생성기와 도형·글자 모음
js/lessons.js     차시 구성(교과서 순서), 활동 분류, 배우기 활동
js/games.js       익히기 게임
js/app.js         화면 이동(홈·차시·활동·게임)
test/geom.test.js 기하 판정·문제 생성기 점검 (node test/geom.test.js)
```

활동 완료 표시와 게임 최고 기록은 그 기기의 브라우저 안(localStorage)에만 저장되며 어디로도 전송되지 않습니다.
