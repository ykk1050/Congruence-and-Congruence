# 합동과 대칭 미술관

『수학 5-2』 3단원 **합동과 대칭**을 스마트 패드로 공부하는 수업용 웹앱입니다.
교과서의 이야기(다윤이와 승현이의 미술관 탐험)를 따라 전시실(차시)을 순서대로 돌면서

- **📘 배우기**: 교과서 순서대로 개념을 탐구하는 활동
- **🎮 익히기 게임**: 상황이 있는 게임으로 매번 새 문제를 반복 연습

을 할 수 있습니다. 설치나 로그인이 필요 없고, 웹 브라우저만 있으면 됩니다.

## 활동 선정 기준

교과서·지도서의 활동을 **실제로 하는 것이 더 좋은 활동**과 **스마트 패드로 하는 것이 더 효과적인 활동**으로 나누고, 앞의 것은 모두 웹앱에서 제외했습니다.

| 💻 웹앱으로 하는 활동 | 📄 종이·실물로 하는 활동 (제외) |
| --- | --- |
| 종이로 하면 도형을 뜯거나 여러 번 다시 그려야 하는 활동 (포개어 대응점·대응변·대응각 찾기) | 색종이 겹쳐 오리기 (합동의 의미를 손으로 경험) |
| 즉각적인 확인과 맞춤형 피드백이 도움이 되는 활동 (대칭축 긋기, 대칭도형 완성하기) | 반으로 접어 보기, 무늬를 선 따라 접어 보기 (선대칭의 의미) |
| 도형을 끌어 바꾸어 보며 성질이 “언제나” 성립하는지 확인하는 탐구 | 준비물로 글자·도형을 직접 180° 돌려 보기 (점대칭의 의미) |
| 반복 연습이 필요한 활동 → 상황이 있는 게임 | 주변에서 찾아 이야기하기, 자유롭게 그림 그리기, 실물 카드 놀이, 알지오매스 활동 |

## 지도서 반영 내용

- 차시마다 지도서의 **학습 지도 및 평가의 주안점**을 “선생님 안내”에 정리했습니다.
- “예상하기 → 직접 확인하기 → 성질 정리하기” 흐름을 따릅니다.
- 그리는 방법을 외우기 전에 **어떤 성질을 이용할지 먼저 생각**하게 하고, 마지막에 방법을 순서대로 정리합니다.
- 대칭축이 모눈과 다른 방향일 때 **수선을 먼저 긋도록** 보조선 도구와 피드백을 제공합니다.
- 뒤집어서 포개어도 합동이라는 점, 가운데 점이 있다고 점대칭도형은 아니라는 점 등 지도서의 **오개념**을 피드백에 반영했습니다.
- 대응점은 5학년 수준에 맞게 **꼭짓점인 경우만** 다룹니다.

## 구조

```
index.html        진입 화면
css/style.css     스타일 (패드 가로 화면 기준, 세로·휴대폰 대응)
js/core.js        DOM/SVG 도우미, 기하 계산(합동·대칭 판정), 저장, 소리
js/stage.js       모눈/도형을 그리는 SVG 무대와 터치 입력
js/ui.js          공용 부품: 단계 진행, 선택·빈칸 문제, 대응 찾기, 대칭축 긋기, 대칭도형 완성, 도형판
js/shapes.js      무작위 문제 생성기와 도형·글자 모음
js/lessons.js     차시 구성(교과서 순서), 활동 분류, 배우기 활동
js/games.js       익히기 게임
js/app.js         화면 이동(홈·차시·활동·게임·교사 안내)
test/geom.test.js 기하 판정·문제 생성기 점검 (node test/geom.test.js)
```

활동 완료 표시와 게임 최고 기록은 그 기기의 브라우저 안(localStorage)에만 저장되며 어디로도 전송되지 않습니다.
